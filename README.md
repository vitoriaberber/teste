# Teste Dev Front-End - Estágio

Este projeto foi desenvolvido como parte de um teste técnico para uma vaga de estágio na área de Desenvolvimento Front-End. O desafio consistia em criar um mini quiz responsivo com HTML, CSS e JavaScript.

## ✨ Funcionalidades

- Interface responsiva para diferentes tamanhos de tela.
- Navegação entre perguntas com botão de seta e botões numerados.
- Ativação dinâmica dos botões conforme as perguntas são respondidas.
- Validação simples de preenchimento para habilitar o botão "Enviar".
- Redirecionamento para página de agradecimento após o envio.

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3 (com media queries para responsividade)
- JavaScript (DOM, eventos, manipulação de classes)

## 💡 Aprendizados

Durante o desenvolvimento, pude reforçar meus conhecimentos sobre:
- Manipulação de DOM com JavaScript puro
- Boas práticas de estruturação semântica no HTML
- Criação de layouts adaptáveis com CSS responsivo

## 📌 Observações

Este projeto é apenas um exercício prático. A lógica pode ser expandida para validação de respostas corretas, timer, barra de progresso e pontuação.
